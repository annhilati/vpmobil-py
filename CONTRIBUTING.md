## Contributing

Momentan sind Reports, Funktions- und Verbesserungsvorschläge im Grunde nur per [Issue](https://github.com/annhilati/vpmobil-py/issues) erwünscht.
Pull Requests werden zwar angesehen, aber in keinem Fall übernommen. Es ist allerdings möglich, dass Änderungen aufgrund eines Pull Requests vorgenommen werden.

Das Ziel dieses Projekts ist momentan, alle in Vertretungsplänen verfügbaren Informationen auf eine für Python übliche und sinnvolle Weise zur Verfügung zu stellen.
Für jede Art von auf Python basierenden Projekt, dass sich mit Indiware-Software befasst soll jede dafür nötige Funktionalität bereitgestellt werden.
