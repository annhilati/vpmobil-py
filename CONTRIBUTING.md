## Contributing

Momentan sind Reports, Funktions- und Verbesserungsvorschläge im Grunde nur per [Issue](https://github.com/annhilati/issues) erwünscht.
Pull Requests werden zwar angesehen, aber in keinem Fall übernommen. Es ist allerdings möglich, dass Änderungen aufgrund eines Pull Requests vorgenommen werden.

Das Ziel dieses Projekts ist momentan, alle in Vertretungsplänen verfügbaren Informationen auf eine für Python übliche und sinnvolle Weise bereitzustellen.
Dadurch sollen alle Arten von auf Python basierenden Projekten zu Indiware die nötige Funktionalität erhalten.
