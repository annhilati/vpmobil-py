# vpmobil-py installieren

### Mit pip

```batch
pip install vpmobil
```

### Manuell

1. Klone das Repostory oder lade es herunter
2. Wechsel in das Hauptverzeichnis des geklonten Repositories
3. Führe den Installationsbefehl aus

```batch
pip install .
```
